# Technical Leadership & Product Mentorship Engine

A training ground for aspiring Technical Product Managers (TPMs / Technical PMs) and Engineering Leaders who combine technical depth with business rigor.

## Curriculum Tracks

1. **[Product Strategy & Execution](exercises/01-product-management/)** — JTBD, personas, metric defensibility, PRDs, prioritization.
2. **[Distributed System Design & Architecture](exercises/02-system-design/)** — Scale math, NFRs, API contracts, caching, event streaming, reliability.
3. **[Data Science, Statistics & Experimentation](exercises/03-data-science/)** — Statistical hypothesis testing, power sizing, bias audits, CUPED.
4. **[Applied Machine Learning & Production MLOps](exercises/04-machine-learning/)** — Baselines first, cost asymmetry, feature stores, drift monitoring, serving topologies.
5. **[Generative AI, RAG & LLM Systems](exercises/05-generative-ai/)** — Retrieval architectures, hybrid search, evals, agentic boundaries, cost & token economics.
