# Track 4: Applied Machine Learning & Production MLOps

Welcome to the Applied Machine Learning & Production MLOps track.

## Focus Areas
- **Baselines First**: Simple heuristic & statistical baselines before complex deep learning architectures.
- **Metric & Cost Asymmetry**: Business cost of False Positives vs. False Negatives, PR-AUC vs. ROC-AUC on imbalanced data.
- **Data Leakage & Split Hygiene**: Temporal splitting, feature transformations strictly fit on train splits, online-offline feature consistency.
- **Production Serving & Drift**: Real-time RPC vs. Batch vs. Streaming, model quantization, fallbacks, KS-test/PSI drift alerting, canary/shadow deployment strategies.
