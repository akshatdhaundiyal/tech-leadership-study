# Track 1: Product Strategy & Execution

Welcome to the Product Strategy & Execution track.

## Focus Areas
- **Problem Space Definition**: Target Personas, Core Jobs-to-be-Done (JTBD), and Current Workarounds.
- **Metric Defensibility**: North Star metrics, input vs. output metrics, and perversion/gaming vulnerability analysis.
- **Prioritization Discipline**: Explicit trade-off frameworks (RICE, Opportunity Solution Trees, Kano analysis).
- **PRD Standards**: Problem-first specifications with measurable baselines and targets before feature enumeration.
