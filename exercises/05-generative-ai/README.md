# Track 5: Generative AI, RAG & LLM Systems

Welcome to the Generative AI, RAG & LLM Systems track.

## Focus Areas
- **Retrieval Architecture**: Semantic/sliding-window chunking, dense embeddings + BM25 hybrid search, re-ranking latency & cost trade-offs.
- **Deterministic vs. Agentic**: State machines & structured JSON outputs over loose multi-agent orchestration.
- **Evaluation Harnesses (Evals)**: Automated test suites, assertion pipelines, and LLM-as-a-judge scoring frameworks.
- **Production Guardrails**: Token budget management, cache hit rates, prompt injection defense, and model fallbacks.
