# Track 2: Distributed System Design & Architecture

Welcome to the Distributed System Design & Architecture track.

## Focus Areas
- **Scale Math & NFRs**: Peak Read/Write QPS, Read:Write ratios, P99 latency SLAs, network egress, and 3-year multi-region storage sizing.
- **Contracts & Interfaces**: Protocol selection (gRPC vs. REST vs. Event streams), idempotency tokens, rate limiting, and schema versioning.
- **Resilience & Storage**: Caching topologies, cache stampede mitigation, Kafka partitioning and lag strategies, dead-letter queues, and CAP trade-offs.
