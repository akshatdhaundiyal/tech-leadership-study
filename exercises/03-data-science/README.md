# Track 3: Data Science, Statistics & Experimentation

Welcome to the Data Science, Statistics & Experimentation track.

## Focus Areas
- **A/B Testing Rigor**: Statistical hypothesis testing, Minimum Detectable Effect (MDE), statistical power ($1-\beta$), significance levels ($\alpha$), and sample size estimation.
- **Experiment Guardrails**: Early-stopping / peeking bias mitigations, variance reduction (CUPED), and novelty effect handling.
- **Data Hygiene**: Survivorship bias, selection bias, covariate shift, and multicollinearity audits.
